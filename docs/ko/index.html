옜다, 화면.비번은 빼고.

Claude Code든 Codex든, 스크린샷을 바로 붙여 주는 맥 앱. API 키·비번은 알아서 가려요.

brew install --cask woonmayer/tap/yetda

아니면 dmg로 받기. 무료 오픈소스, macOS 13 이상, Apple 서명·공증. 맥 밖으로는 아무것도 안 보내요.

⌘ 두 번.

어느 앱에서든. ⌘⇧2도 돼요. 영역을 드래그하거나, 스페이스로 창 하나 통째로.

API 키가 찍혀도 괜찮아요.

이미지가 어디로 가기 전에 맥 안에서 먼저 가려요. 기기 안 OCR로 찾고, Apple Intelligence가 켜진 맥에서는 온디바이스 모델이 한 번 더 봐요.

쓰던 데로 붙어요.

마지막에 쓰던 터미널이나 앱으로, 그 앱에 맞는 키로 붙여요.

Terminal, iTerm2, Ghostty, Warp, WezTerm, kitty, Alacritty, Hyper, cmux, Orca, Kaku, 그리고 Claude·Codex·ChatGPT 앱. 다른 앱도 메뉴에서 추가할 수 있어요.

그 밖에

  • ⌘⇧1로 최근 10장을 다시 붙여요.
  • Claude Code나 Codex에서 /shots로 여러 장을 한 번에 넘겨요.
  • 읽은 글자를 같이 붙일 수도 있어요.
  • 캡처는 7일 뒤 지워져요.

설치

위 brew 한 줄을 실행하거나, dmg를 열어 응용 프로그램 폴더로 옮기세요. 처음 쓸 때 화면 기록·손쉬운 사용 권한을 물어봐요.

소스에서 직접 빌드하기 
# 빌드
git clone https://github.com/woonmayer/yetda.git
cd yetda
./scripts/build-app.sh

# 설치 (macOS 권한이 유지되도록 복사 말고 이동)
rm -rf /Applications/Yetda.app && mv Yetda.app /Applications/
open /Applications/Yetda.app

자주 묻는 질문

비밀 정보는 어떻게 가리나요?

macOS 기기 안 OCR로 캡처의 글자를 읽고, 알려진 키 형식(OpenAI, Anthropic, GitHub, AWS, Stripe, JWT 등), password=… 같은 값, 카드번호를 찾아 이미지와 붙는 글자 양쪽에서 가려요. Apple Intelligence가 켜진 Mac에서는 Apple의 온디바이스 LLM이 무작위처럼 보이는 문자열도 맥 안에서 한 번 더 판단해요(클라우드 호출 없음). 가리는 도중 문제가 생기면 아예 붙여넣지 않아요. 너무 많이 가렸다면 Paste Last Capture Without Hiding으로 원본을 붙일 수 있어요(원본은 메모리에만 보관). 어떤 데이터도 밖으로 나가지 않아요. 다만 안전망이니, 보내기 전에 한 번 훑어봐 주세요.

손쉬운 사용 권한은 왜 필요한가요?

⌘ 두 번 누르기를 알아채고, 터미널에서 붙여넣기 키를 누르기 위해서예요. 권한이 없어도 캡처는 클립보드에 들어가니 직접 붙여넣으면 돼요.

제 터미널이 목록에 없어요.

그 앱을 쓰다가 메뉴바 메뉴의 Paste Into에서 Add “앱 이름”을 고르거나, Add App…으로 아무 앱이나 고르면 돼요. 앱마다 ⌃V·⌘V를 고를 수 있어요.

Codex(또는 다른 앱)가 이미 ⌘⌘를 써요.

메뉴에서 “Capture with ⌘⌘”를 끄고 ⌘⇧2를 쓰세요.

캡처가 빈 화면으로 나오거나 권한 창이 계속 떠요.

Mac에 Yetda.app이 하나만 있는지 확인한 뒤 tccutil reset ScreenCapture io.github.woonmayer.yetda를 실행하고, 앱을 다시 켜서 권한을 다시 주세요.

어떤 에이전트에서 동작하나요?

붙여넣은 이미지를 받는 터미널 에이전트라면 다 돼요: Claude Code, Codex, Gemini CLI, opencode 등. Yetda는 ⌃V(iTerm2는 ⌘V)를 눌러요. Cursor CLI처럼 어디서든 ⌘V를 쓰는 에이전트라면 메뉴의 Paste Into에서 그 터미널을 ⌘V로 바꾸세요. Claude·Codex·ChatGPT 데스크톱 앱에도 ⌘V로 붙여요. 다른 앱도 메뉴에서 추가할 수 있어요. /shots 스킬은 Claude Code와 Codex에서 동작해요.
