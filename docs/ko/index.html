설치

Homebrew로 설치하거나 앱을 내려받으세요. macOS 13 이상, Apple 서명·공증을 마친 앱이에요.

# Homebrew
brew install --cask woonmayer/tap/yetda

Yetda.dmg 내려받기 dmg를 열고 Yetda를 응용 프로그램 폴더로 끌어다 놓으세요.

소스에서 직접 빌드하기 
# 빌드
git clone https://github.com/woonmayer/yetda.git
cd yetda
./scripts/build-app.sh

# 설치 (macOS 권한이 유지되도록 복사 말고 이동)
rm -rf /Applications/Yetda.app && mv Yetda.app /Applications/
open /Applications/Yetda.app

처음 쓸 때 macOS가 화면 기록(캡처용)과 손쉬운 사용(⌘⌘와 자동 붙여넣기용) 권한을 물어봐요. 빠진 권한이 있으면 메뉴 맨 위에 ⚠︎ 항목이 떠서 해당 설정 화면을 바로 열어줘요. 처음 실행할 때는 Claude Code와 Codex에 /shots 스킬을 설치할지도 한 번 물어봐요. 묻지 않고 설치하는 일은 없어요.

자주 묻는 질문

비밀 정보는 어떻게 가리나요?

macOS 기기 안 OCR로 캡처의 글자를 읽고, 알려진 키 형식(OpenAI, Anthropic, GitHub, AWS, Stripe, JWT 등), password=… 같은 값, 카드번호를 찾아 이미지와 붙는 글자 양쪽에서 가려요. Apple Intelligence가 켜진 Mac에서는 Apple의 기기 내 모델이 무작위처럼 보이는 문자열도 한 번 더 판단해요. 가리는 도중 문제가 생기면 아예 붙여넣지 않아요. 너무 많이 가렸다면 Paste Last Capture Without Hiding으로 원본을 붙일 수 있어요(원본은 메모리에만 보관). 어떤 데이터도 밖으로 나가지 않아요. 다만 안전망이니, 보내기 전에 한 번 훑어봐 주세요.

손쉬운 사용 권한은 왜 필요한가요?

⌘ 두 번 누르기를 알아채고, 터미널에서 붙여넣기 키를 누르기 위해서예요. 권한이 없어도 캡처는 클립보드에 들어가니 직접 붙여넣으면 돼요.

제 터미널이 목록에 없어요.

그 터미널을 쓰다가 메뉴바 아이콘을 누르면 Also Paste into “앱 이름” 항목이 보여요. 체크하면 자동 붙여넣기 대상이 돼요.

Codex(또는 다른 앱)가 이미 ⌘⌘를 써요.

메뉴에서 “Capture with ⌘⌘”를 끄고 ⌘⇧2를 쓰세요.

캡처가 빈 화면으로 나오거나 권한 창이 계속 떠요.

Mac에 Yetda.app이 하나만 있는지 확인한 뒤 tccutil reset ScreenCapture io.github.woonmayer.yetda를 실행하고, 앱을 다시 켜서 권한을 다시 주세요.

어떤 에이전트에서 동작하나요?

붙여넣은 이미지를 받는 터미널 에이전트라면 다 돼요: Claude Code, Codex, Gemini CLI, opencode 등. Yetda는 ⌃V(iTerm2는 ⌘V)를 눌러요. Cursor CLI처럼 어디서든 ⌘V를 쓰는 에이전트라면 메뉴에서 Paste Key → ⌘V로 바꾸세요. Claude·Codex·ChatGPT 데스크톱 앱에도 ⌘V로 붙여요. 다른 앱도 메뉴에서 추가하고 ⌃V·⌘V를 고를 수 있어요. /shots 스킬은 Claude Code와 Codex에서 동작해요.
