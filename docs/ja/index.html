Yetda
English한국어日本語

画面は見せて、鍵は隠す。

Claude CodeでもCodexでも、スクショをそのまま貼れるMacアプリ。APIキーやパスワードは自動で隠します。

brew install --cask woonmayer/tap/yetda

またはdmgをダウンロード。無料・オープンソース、macOS 13以降、Apple署名・公証済み。Macの外には何も送りません。

⌘を2回。

どのアプリからでも。⌘⇧2でも。範囲をドラッグ、またはスペースでウィンドウ全体。

APIキーが写っていても大丈夫。

画像がどこかへ行く前に、Macの中で先に隠します。端末内OCRで見つけ、Apple Intelligence対応のMacではオンデバイスモデルがもう一度確認します。

使っていた場所へ。

最後に使ったターミナルかアプリに、そのアプリに合ったキーで貼ります。

Terminal、iTerm2、Ghostty、Warp、WezTerm、kitty、Alacritty、Hyper、cmux、Orca、Kaku、そしてClaude・Codex・ChatGPTのアプリ。ほかのアプリもメニューから追加できます。

ほかにも

  • ⌘⇧1で直近10枚を貼り直せます。
  • Claude CodeやCodexで/shotsを使えば複数枚を一度に。
  • 読み取ったテキストも一緒に貼れます。
  • キャプチャは7日後に消えます。

インストール

上のbrewを実行するか、dmgを開いてアプリケーションフォルダへ。初回に画面収録とアクセシビリティの許可を求めます。

ソースからビルドする 
# ビルド
git clone https://github.com/woonmayer/yetda.git
cd yetda
./scripts/build-app.sh

# インストール（macOSの権限を保つため、コピーではなく移動）
rm -rf /Applications/Yetda.app && mv Yetda.app /Applications/
open /Applications/Yetda.app

よくある質問

秘密情報はどうやって隠すの？

macOSの端末内OCRでスクショの文字を読み取り、既知のキー形式（OpenAI、Anthropic、GitHub、AWS、Stripe、JWTなど）、password=…のような値、カード番号を見つけて、画像と貼り付けるテキストの両方で隠します。Apple Intelligenceが有効なMacでは、AppleのオンデバイスLLMがランダムに見える文字列もMacの中でもう一度判定します（クラウド呼び出しなし）。隠す途中で問題が起きたら、そもそも貼り付けません。隠しすぎたときはPaste Last Capture Without Hidingで元の画像を貼れます（元画像はメモリにだけ保持）。データは一切外に出ません。ただし安全網なので、送る前に一度確認してください。

なぜアクセシビリティの許可が必要？

⌘の2回押しを検知して、ターミナルで貼り付けキーを押すためです。許可がなくてもキャプチャはクリップボードに入るので、手動で貼り付けられます。

使っているターミナルがリストにない。

そのアプリを使っている状態でメニューバーのメニューのPaste IntoからAdd “アプリ名”を選ぶか、Add App…で任意のアプリを選んでください。アプリごとに⌃Vか⌘Vを選べます。

Codex（または他のアプリ）がもう⌘⌘を使っている。

メニューで「Capture with ⌘⌘」をオフにして、⌘⇧2を使ってください。

キャプチャが真っ白になる、または許可ダイアログが何度も出る。

MacにYetda.appが1つだけあることを確認してからtccutil reset ScreenCapture io.github.woonmayer.yetdaを実行し、アプリを再起動して許可し直してください。

どのエージェントで使える？

画像の貼り付けを受け付けるターミナルエージェントならどれでも：Claude Code、Codex、Gemini CLI、opencodeなど。Yetdaは⌃V（iTerm2では⌘V）を押します。Cursor CLIのようにどこでも⌘Vを使うエージェントなら、メニューのPaste Intoでそのターミナルを⌘Vに変えてください。Claude・Codex・ChatGPTのデスクトップアプリにも⌘Vで貼り付けます。ほかのアプリもメニューから追加できます。/shotsスキルはClaude CodeとCodexで使えます。
