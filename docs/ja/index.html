インストール

Homebrewでインストールするか、アプリをダウンロードしてください。macOS 13以降、Appleの署名・公証済みです。

# Homebrew
brew install --cask woonmayer/tap/yetda

Yetda.dmgをダウンロード dmgを開いて、Yetdaをアプリケーションフォルダへドラッグしてください。

ソースからビルドする 
# ビルド
git clone https://github.com/woonmayer/yetda.git
cd yetda
./scripts/build-app.sh

# インストール（macOSの権限を保つため、コピーではなく移動）
rm -rf /Applications/Yetda.app && mv Yetda.app /Applications/
open /Applications/Yetda.app

初回利用時に、macOSが画面収録（キャプチャ用）とアクセシビリティ（⌘⌘と自動貼り付け用）の許可を求めます。足りない許可があると、メニューの一番上に⚠︎項目が出て、該当する設定画面をすぐ開けます。初回起動時には、Claude CodeとCodexに/shotsスキルを入れるかどうかも一度だけ聞きます。聞かずに入れることはありません。

よくある質問

秘密情報はどうやって隠すの？

macOSの端末内OCRでスクショの文字を読み取り、既知のキー形式（OpenAI、Anthropic、GitHub、AWS、Stripe、JWTなど）、password=…のような値、カード番号を見つけて、画像と貼り付けるテキストの両方で隠します。Apple Intelligenceが有効なMacでは、Appleの端末内モデルがランダムに見える文字列ももう一度判定します。隠す途中で問題が起きたら、そもそも貼り付けません。隠しすぎたときはPaste Last Capture Without Hidingで元の画像を貼れます（元画像はメモリにだけ保持）。データは一切外に出ません。ただし安全網なので、送る前に一度確認してください。

なぜアクセシビリティの許可が必要？

⌘の2回押しを検知して、ターミナルで貼り付けキーを押すためです。許可がなくてもキャプチャはクリップボードに入るので、手動で貼り付けられます。

使っているターミナルがリストにない。

そのターミナルを使っている状態でメニューバーのアイコンを押すと、Also Paste into “アプリ名”が表示されます。チェックすると自動貼り付けの対象になります。

Codex（または他のアプリ）がもう⌘⌘を使っている。

メニューで「Capture with ⌘⌘」をオフにして、⌘⇧2を使ってください。

キャプチャが真っ白になる、または許可ダイアログが何度も出る。

MacにYetda.appが1つだけあることを確認してからtccutil reset ScreenCapture io.github.woonmayer.yetdaを実行し、アプリを再起動して許可し直してください。

どのエージェントで使える？

画像の貼り付けを受け付けるターミナルエージェントならどれでも：Claude Code、Codex、Gemini CLI、opencodeなど。Yetdaは⌃V（iTerm2では⌘V）を押します。Cursor CLIのようにどこでも⌘Vを使うエージェントなら、メニューでPaste Key → ⌘Vに変えてください。/shotsスキルはClaude CodeとCodexで使えます。
